📂 GitHub Resource Manager

Your teaching materials are managed through GitHub. Upload your images directly to the repository and update the resources.json file.

📝 How to Update Images

  1. Open your GitHub repository.
  2. Upload your lesson images inside:
    images → Grade → Subject → Week
  3. Update the resources.json file.
  4. Click: Commit Changes
  5. Refresh your TEACHER MARY HQ website.

📁 Recommended File Format

  images │ ├── Grade3 │    └── Computer │          ├── Week1.png │          ├── Week2.png │          └── Week3.png  resources.json
